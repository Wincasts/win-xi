# Downloads

The newest package of each addon, as one list. Each zip is extracted into your Ashita folder (the one
holding `addons`, `plugins` and `config`), merging folders. Then follow the `INSTALL.txt` inside it.
A beta is a full release, ready to use, that is still being tested in play: please report anything
that goes wrong. The full history is on the
[Releases](https://github.com/Wincasts/win-xi/releases) page.
